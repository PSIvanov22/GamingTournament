# GamingTournament

Уеб приложение за организиране на гейминг турнири: отбори, играчи, треньори, мачове и резултати на едно място. Изградено с **ASP.NET Core MVC** и **Entity Framework Core**.

## Възможности

### За всички посетители
- Начална страница със статистика (отбори, играчи, изиграни и предстоящи мачове), предстоящи мачове и последни резултати
- Преглед на отборите (със странициране), мачовете и турнирите
- Регистрация и вход

### За регистрирани потребители
- Кандидатстване за **играч** в отбор
- Кандидатстване за **треньор** на отбор
- Следене на статуса на заявките директно в списъка с отбори

Един потребител може да е играч само в един отбор, а треньорът на отбор не може да бъде играч.

### За администратори
- Създаване на отбори, турнири и мачове
- Одобряване и отхвърляне на заявки за играчи и за треньори
- Въвеждане на резултат от мач и отмяна на предстоящ мач

## Технологии

- C# и .NET 9
- ASP.NET Core MVC (Razor изгледи)
- ASP.NET Core Identity (потребители и роли)
- Entity Framework Core 9 със SQL Server
- Bootstrap 5 с тъмна гейминг тема

## Структура на проекта

```
GamingTournament/
├── Areas/Identity/     # Страници за вход и регистрация
├── Controllers/        # Home, Teams, Matches, Tournaments
├── Data/               # ApplicationDbContext, миграции, начални данни (SeedData)
├── Models/             # Team, Match, Tournament, заявки, view модели
├── Views/              # Razor изгледи

```

## Стартиране

### Изисквания
- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- SQL Server или SQL Server LocalDB
- Rider, Visual Studio или друга среда за .NET (по желание)

### Стъпки

1. Клонирай репото:
   ```
   git clone https://github.com/PSIvanov22/GamingTournament.git
   cd GamingTournament/GamingTournament
   ```

2. Провери connection string-а в `appsettings.json` и го промени, ако ползваш друг сървър:
   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Server=(localdb)\\MSSQLLocalDB;Database=GamingTournament;Trusted_Connection=True;TrustServerCertificate=True;"
   }
   ```

3. Стартирай приложението:
   ```
   dotnet run
   ```

4. Отвори адреса, който се показва в конзолата (по подразбиране `http://localhost:5222`).

При първо стартиране приложението **автоматично създава базата и прилага миграциите**, после попълва начални данни: няколко отбора, играчи, треньори, турнири, заявки и мачове. Данните се добавят само ако базата още няма отбори.

## Правила за заявките

- Заявката за играч или треньор остава в статус „чака одобрение“, докато администратор не я одобри или отхвърли.
- Отбор може да има най-много един треньор.
- Мач може да получи резултат само докато е предстоящ. Приключилите и отменените мачове не се променят.
